# 発見フェーズ所見（findings.md）

**対象:** コイン投げ（表か裏か）予想ゲーム — Web アプリ
**担当:** 発見の神官（web-scout ＋ feature-ranker の両信徒を兼任）

---

## 1. 本当のニーズ（The Real Need）

ユーザーが求めているのは「**表か裏かを選び、公平なコインを投げ、結果を見て、当たったか外れたかを一瞬で知る**」という、ごく短い運試しのループである。

- 期待される体験は「1クリックで完結する遊び」であり、学習コスト・登録・待ち時間はゼロが理想。
- 中核の情緒的報酬は **予想 → めくり → 正解/不正解の判定** という緊張と解放の反復。
- 実用面では「決めごとの二択（じゃんけん代わり／どっちにするか迷ったとき）」の用途もあるが、v1 では「当てる遊び」を主軸に据える。

---

## 2. 先行事例（Prior Art）— web-scout 所見

この種のゲームは Web 上に無数に存在し、実装の「共通形（common shape）」はほぼ確立している。

- **オンライン・コインフリッパー系**（Google の "flip a coin"、各種 coin-flip サイト）
  - 巨大なコイン画像を中央に置き、ボタン1つで回転アニメーション → 表/裏を提示。
  - 多くは「予想して当てる」より「単純にランダム結果を出す」判定ツール寄り。
- **表裏あてゲーム系**（heads or tails guessing game）
  - 先に「表 or 裏」を選ばせ、投げて、**Correct! / Wrong!** を表示。連勝数やスコアを添えるものが多い。
- **共通する UI 骨格:**
  1. 中央に大きなコインのビジュアル（表/裏の2面）。
  2. 「Heads / Tails」の二択ボタン。
  3. 「Flip（投げる）」トリガー。
  4. コインの回転アニメーション（0.5〜1.5秒）。
  5. 結果テキスト（表/裏）＋ 正誤判定（当たり／外れ）。
  6. スコア／連勝カウンタと「もう一度」導線。
- **技術的共通点:** クライアント完結（サーバ不要）、`Math.random()` による公平な二値抽選、CSS transform／keyframes による3D回転演出。アカウントもDBも持たないのが定番。

## 3. 特徴ランドスケープ表（Feature Landscape）— feature-ranker 所見

採用率（adoption）でランク付け。🔴＝ほぼ全実装が持つ必須、🟠＝多くが持つ高価値、🟡＝一部が持つ付加価値。

| 優先度 | 機能 | 採用度の目安 | 補足 |
|--------|------|--------------|------|
| 🔴 必須 | **表か裏かを選ぶ（pick heads or tails）** | ほぼ全て | 予想ゲームの前提。二択入力。 |
| 🔴 必須 | **公平なランダムでコインを投げる（flip a fair coin）** | ほぼ全て | 50/50 の均等抽選。 |
| 🔴 必須 | **結果を提示する（reveal the result）** | ほぼ全て | 表／裏を明示。 |
| 🔴 必須 | **当たり/外れの判定（right or wrong）** | ほぼ全て | 予想と結果の照合を表示。 |
| 🟠 高 | 連勝/連敗またはスコアカウンタ | 多数 | 継続動機（リプレイ性）を生む。 |
| 🟠 高 | もう一度遊ぶ（play-again） | 多数 | ループを閉じる導線。 |
| 🟠 高 | コインの明確なビジュアル | 多数 | 表/裏が一目で分かる図。 |
| 🟠 高 | 投げるアニメーション | 多数 | 緊張と解放の演出。体感品質を左右。 |
| 🟡 付加 | 効果音（サウンド） | 一部 | 没入感を高めるが必須ではない。 |
| 🟡 付加 | 投げた履歴（history of flips） | 一部 | 過去の結果ログ。 |
| 🟡 付加 | 表/裏の統計（statistics） | 一部 | 表と裏の出現回数・割合。 |

## 4. 推奨 v1 スコープ（Recommended v1 Scope）

**v1 は 🔴 必須の完全実装 ＋ 🟠 高価値のうち体験を成立させる最小セットに絞る。**

- 🔴 必須4機能はすべて実装（下記スペック節に明記）。
- 🟠 からは体験の質を担保するため **以下を v1 に含める:**
  - コインの明確なビジュアル（表/裏2面）
  - 投げるアニメーション（回転演出）
  - 「もう一度」導線
  - スコア／連勝カウンタ（軽量な継続動機）
- 🟡（サウンド・履歴・統計）は **v1 対象外**。将来拡張の候補として残す。

設計方針: **クライアント完結・サーバ/DB なし・登録なし**。1画面で完結し、初見でも説明不要な UI。

---

## 5. スペック用 🔴 必須機能（明示）

仕様書へそのまま渡す必須要件（MUST-HAVE）:

1. **表か裏かを選ぶ** — ユーザーが「表（Heads）」または「裏（Tails）」を選択できる。
2. **公平なコインを投げる** — 50/50 の均等な乱数で表/裏を決定する。
3. **結果を提示する** — 投げた結果（表 or 裏）を明確に表示する。
4. **正誤を伝える** — ユーザーの予想と結果を照合し、「当たり（正解）」か「外れ（不正解）」かを表示する。

---

## 6. 非目標（NON-GOALS）— 明示的に作らない

- **賭け／金銭（betting / money）** — 通貨・ベット・課金・報酬換金は一切扱わない。
- **マルチプレイヤー（multiplayer）** — 対人対戦・オンライン同期・ルーム機能は含めない。
- **アカウント（accounts）** — サインアップ／ログイン／プロフィール／サーバ保存は含めない。

これらは v1 のスコープ外であり、単一ユーザー・単一画面・クライアント完結の原則を崩さない。
