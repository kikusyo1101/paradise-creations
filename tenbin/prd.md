## 1. プロダクト定義

### 1-1. 価値命題(1文)

**天秤は、加重和で出した「勝者」に対して「その結論は、どの基準の重みを何ポイント動かせば崩れ、それ以外では崩れないか」を閉形式で即座に答える、単一HTMLファイルの意思決定ツールである。**

根拠: findings §4-3① —「順位を出すツール」は飽和しているが、「その順位を信じてよいかを数値で答えるツール」は無料層に一つも存在しない。analysis §1 は3場面すべての詰まりが「計算能力ではなく出力の形」にあると結論している。

### 1-2. 対象ユーザー

| 対象 | 状況 | 根拠 |
|---|---|---|
| **締切のある個人決断者** | 転職オファー2社を今夜中に決める。基準4個・選択肢2件。0.3点差が僅差なのか判断できない | analysis §1 場面A / findings §3-4(c) |
| **説明責任を負う小チームの調達担当** | 3社のベンダー/SaaS を選び、上長に「価格の重みをもう少し高く見ていたら結論は変わったのか」と問われる。基準4〜5個・選択肢3社 | analysis §1 場面B / findings §4-1 |
| **重みに自信が持てない一回きりの人生判断者** | 引っ越し先・進学先。選択肢3〜4件・基準5個前後。「何を重視すべきか」自体を決めかねている | analysis §1 場面C / findings §4-2-2 |

共通条件: **無料で、登録せず、ブラウザを開いてすぐ、サーバーに何も送らずに使える**ことを最低条件とする層(findings §2🔴「無料Webツール群8つ中7つが登録不要・サーバー送信なしを最大の訴求点に据えている」)。

### 3-B. 感度分析 — 中核(analysis §3)

| ID | 要件 | 対応 US | 参照 |
|---|---|---|---|
| **FR-08** | **逆転閾値の算出。** 1位 `W` と各挑戦者 `i` について `D₀^(i) = S_W − S_i`、`d_k^(i) = a_Wk − a_ik` を求め、実行可能な (k, i) 組について `Δw_k^(i) = D₀^(i)(1 − w_k) / (D₀^(i) − d_k^(i))` を計算する。基準 k の閾値は全挑戦者にわたる `|Δw_k^(i)|` の最小値、その argmin を「逆転相手」として保持する。新しい重みは `w_k* = w_k + Δw_k` | US-05 | analysis §3-1 / §3-4 |
| **FR-09** | **実行可能性判定。** `逆転可能 ⟺ d_k < 0(上げて逆転) または w_k·d_k > D₀(下げて逆転)`。それ以外(`d_k ≥ 0` かつ `w_k·d_k ≤ D₀`)は**支配的優位**とし `Δw_k = ∞`、感度係数 `sens_k = 0`。実行可能なら `sens_k = 1/|Δw_k|`。`d_k = D₀` の場合も分母0のため `Δw_k = ∞` として扱う | US-07 | analysis §3-2 |
| **FR-10** | **臨界度ランキングの表示。** 全基準を `|Δw_k|` 昇順で並べる。**逆転不能な基準は末尾に「逆転不能」として理由文付きで置く。** 各行に表示すべき数値は次の5つ:<br>① 基準名 ② 現在の重み `w_k`(%、小数1桁) ③ 逆転する重み `w_k*`(%、小数1桁) ④ 変化量 `Δw_k`(ポイント、小数1桁、**必ず符号付き**) ⑤ 逆転相手の選択肢名<br>行の文言テンプレート: 「**{基準名} — 現在 {w_k}% → {w_k*}%({±Δ}ポイント)で {逆転相手} に逆転**」<br>逆転不能な行の文言テンプレート: 「**{基準名} — 逆転不能。{W} がこの基準でも勝っている(または差が僅少)ため、重みを上げても {W} のリードが広がるだけです。**」 | US-06, US-07 | analysis §3-4 / §3-2 / findings §3-4(c) |
| **FR-11** | **頑健性ラベルと一次出力文。** `Δ* = min_k |Δw_k|`(実行可能な基準のみ、1つも無ければ `∞`)、`k* = argmin_k |Δw_k|`。ラベルは `Δ* = ∞ → robust` / `Δ* ≤ θ → fragile` / `θ < Δ* < ∞ → contingent`(既定 `θ = 0.10`)。**ラベルは必ず生の数値 `Δ*` と理由文とセットで表示し、ラベル単独では表示しない。** 文言テンプレートは §5 に確定 | US-05, US-08 | analysis §3-6 / §5-4 |
| **FR-12** | **θ の設定と由来の明示。** `θ` はユーザーが変更可能な設定項目とし、**既定値 0.10 の由来(yesnowheelapp が 8.5 ポイントのシフトで逆転する事例を「真に僅差の決定」と総括したこと)と、理論的裏付けを持たない経験則であることをツールチップに明記する** | US-08 | analysis §3-6 / §5-4 |
| **FR-13** | **勝敗貢献度(B)の表示。** 1位 `W` と既定の挑戦者 `L`(=2位)について `g_j = w_j·(a_Wj − a_Lj) / D₀`(`Σ_j g_j = 1`)を全基準について表示する。**`g_j < 0` の基準は逆符号のバーで表示する。** 各バーには必ず数値ラベル(%、小数1桁、符号付き)を併記する。`D₀ = 0` のときは表示せず FR-19 のメッセージに切り替える | US-09 | analysis §3-5(B) |
| **FR-14** | **スコア貢献度(A)の表示。** 選択肢 i ごとに `c_ij = w_j·a_ij / S_i`(`Σ_j c_ij = 1`)を表示する。`S_i = 0` のときは `c_ij` を未定義とし「**—**」を表示する。**(A)(B) いずれも「学術的に検証された指標」とは称さない**(findings §5 の通り分解式の一次資料は未確認) | US-09 | analysis §3-5(A) / findings §5 |
| **FR-15** | **挑戦者の切替。** FR-13 の `L` は既定で2位とするが、選択肢が3件以上ある場合はユーザーが挑戦者を選び直せる。FR-08 / FR-10 / FR-11 は常に**全挑戦者**を対象に計算する(挑戦者の選択は貢献度表示にのみ影響する) | US-09 | analysis §3-4 |

## 付録: 実装者向け計算サマリ(analysis.md 付録の転記 — 式を変えないこと)

```
入力:  raw_ij ∈ [0,10],  dir_j ∈ {benefit, cost},  ŵ_j ≥ 0

正規化:  a_ij = raw_ij/10                (dir_j = benefit)
         a_ij = (10 − raw_ij)/10         (dir_j = cost)
         w_j  = ŵ_j / Σ_j' ŵ_j'

スコア:  S_i = Σ_j w_j · a_ij            表示は S_i × 100

順位:    W = argmax_i S_i,  挑戦者は残り全て

逆転閾値(基準 k、挑戦者 i):
         D₀ = S_W − S_i ,  d_k = a_Wk − a_ik
         実行可能 ⟺ d_k < 0  または  w_k·d_k > D₀
         Δw_k = D₀(1 − w_k) / (D₀ − d_k)      新重み w_k* = w_k + Δw_k
         実行不能なら Δw_k = ∞, sens_k = 0 ; それ以外 sens_k = 1/|Δw_k|

比例再正規化(スライダー挙動と一致させること):
         w_j(x) = w_j × (1 − x)/(1 − w_k)     (j ≠ k)
         w_k(x) = x                            Σ_j w_j(x) = 1

臨界度:  Δ*_k = min over 挑戦者 i の |Δw_k^(i)| ,  ランキングは Δ*_k 昇順
         Δ*   = min_k Δ*_k ,  k* = argmin_k Δ*_k

貢献度:  c_ij = w_j·a_ij / S_i                      (スコア貢献度, Σ_j = 1)
         g_j  = w_j·(a_Wj − a_Lj) / D₀              (勝敗貢献度,  Σ_j = 1)
         恒等: g_k ≤ 1 ⟺ 基準 k は下方向に逆転不能

ラベル:  Δ* = ∞      → robust
         Δ* ≤ θ      → fragile        (θ 既定 0.10、ユーザー変更可)
         それ以外    → contingent

逆算検知: 重み編集履歴で1位が入れ替わった回数 f ≥ 3 → 警告
```
