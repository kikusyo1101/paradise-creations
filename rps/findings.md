# じゃんけんゲーム（対コンピュータ）— 市場調査 / findings

対象の願い（wish）: 「対コンピュータのじゃんけんゲーム（Webアプリ）」

本書は discover フェーズの成果物であり、次の spec フェーズへの入力となる。
🔴 must-have は仕様の必須要件として明示的に名前を付けている。

---

## 1. 本当のニーズ（リテラルな依頼の先）

字義どおりには「グー・チョキ・パーを選ぶと勝敗が出る」だが、ユーザーが実際に求めているのは以下：

- **即座に遊べる手軽な暇つぶし**。ログイン・チュートリアル・ロードなしで、開いた瞬間に1回目が遊べること。
- **明確で気持ちの良いフィードバック**。自分の手・相手の手・勝敗が一目で分かり、「なぜ勝った/負けたか」が瞬時に理解できること。
- **繰り返し遊びたくなるループ**。1回で終わらず、スコアが積み上がり「もう1回」を押したくなる小さな達成感。
- **公平さの体感**。コンピュータがズルをしていない（後出ししていない）と信じられること。演出上は同時に出す。
- **どこでも動く**。スマホのタップでもPCのクリック/キーボードでも遊べ、インストール不要。

要するに「**1画面で完結する、即応・明快・反復可能な軽量ゲーム**」が真のニーズ。作り込みより「摩擦ゼロ」と「明快さ」が価値の中心。

---

## 2. 先行事例（Prior art）— よくあるRPS Webゲームと共通点

実在の典型例（教育チュートリアル、CodePen作品、シンプルなゲームサイト、Google検索の "play rock paper scissors" 内蔵ゲーム等）に広く見られる構成：

- **3ボタン（グー/チョキ/パー）を並べた1画面UI**。アイコン（✊✋✌ や 石/紙/ハサミの絵）＋ラベル。
- **プレイヤー手 vs コンピュータ手を左右で対比表示**し、中央または上部に勝敗テキスト（WIN / LOSE / DRAW）。
- **コンピュータの手は乱数（0/1/2）で選択**するのが圧倒的多数。
- **累積スコア（You x - y CPU）を画面に常時表示**。多くはローカル状態のみで永続化なし。
- **「もう一度 / リセット」導線**が必ずある。
- **クライアント完結（HTML/CSS/JS のみ）**。サーバ・DB・通信なし。1ページで完結し、静的ホスティングで動く。

共通する骨格 = 「3択入力 → 相手の手を乱数決定 → ルール判定（グー>チョキ>パー>グー）→ 手と結果の表示 → スコア更新 → 再戦」。この最小ループがジャンル標準。

## 3. 機能ランドスケープ（採用率順・優先度マーカー付き）

| 優先 | 機能 | 説明 | 採用率の目安 |
|------|------|------|--------------|
| 🔴 | **手の選択（グー/チョキ/パー）** | クリック/タップで3択を選べる | ほぼ100%（定義そのもの） |
| 🔴 | **コンピュータの手を決定・表示** | 乱数で相手の手を選び、画面に見せる | ほぼ100% |
| 🔴 | **勝敗判定（勝ち/負け/あいこ）** | 標準ルールで結果を計算 | ほぼ100% |
| 🔴 | **結果の表示** | WIN/LOSE/DRAW を明確なテキスト/色で提示 | ほぼ100% |
| 🟠 | **スコア追跡（複数ラウンド）** | 勝ち数・負け数（＋あいこ）を累積表示 | 高（多数派） |
| 🟠 | **もう一度 / リセット** | 次ラウンド開始・スコアクリア導線 | 高 |
| 🟠 | **明確な視覚フィードバック** | 選択中ハイライト、結果に応じた色/強調 | 高 |
| 🟠 | **クリック＋キーボード入力** | タップ/クリックに加え R/P/S や 1/2/3 キー対応 | 中〜高 |
| 🟡 | **Best-of-N（3本先取など）** | 一定勝利数で「試合」に決着 | 中 |
| 🟡 | **アニメーション** | 手を振る演出、結果のトランジション | 中 |
| 🟡 | **効果音** | 選択音・勝敗音（ミュート可が望ましい） | 低〜中 |
| 🟡 | **選択履歴 / 直近ログ** | 各ラウンドの手と結果の一覧 | 低 |
| 🟡 | **非乱数AI（癖読み等）** | 直前の手から次を予測して優位を狙う | 低（差別化要素） |
| 🟡 | スコア永続化（localStorage） | リロード後もスコア保持 | 低 |

## 4. 推奨スコープ（credible v1）と NON-GOALS

### v1 の必須（🔴 must-have — spec で必ず満たす）
1. **グー/チョキ/パーの3択入力**（クリック/タップ）。
2. **コンピュータの手を乱数で決定し、画面に表示**（後出しに見えない演出）。
3. **標準ルールで勝敗（勝ち/負け/あいこ）を判定**。
4. **結果を明確に表示**（WIN/LOSE/DRAW のテキスト＋色）。

### v1 に含めたい（🟠 high — 「credible」に必要な水準）
5. **スコア追跡**（You 勝ち数 / CPU 勝ち数、あいこ数も）。
6. **もう一度 / リセット** ボタン。
7. **明確な視覚フィードバック**（自分の手・相手の手の対比、結果に応じた色）。
8. **キーボード入力**（例: R/P/S または 1/2/3。クリックと併用）。

### 任意（🟡 — 余力があれば1つ2つ）
- Best-of-N（例: 5本勝負）、簡単なアニメーション、選択履歴、ミュート可能な効果音。

### 明確な NON-GOALS（v1 でやらない）
- **マルチプレイヤー / 対人対戦**（オンライン・ローカル問わず）。
- **アカウント / ログイン / プロフィール**。
- **ネットワーク通信 / サーバ / DB / 外部API**（クライアント完結、静的配信で動く）。
- **ランキング / リーダーボード / SNS共有**。
- **課金・広告・アナリティクス**。

**設計方針**: 単一 HTML ページ（HTML/CSS/JS）で完結。ビルド不要・依存なしで `index.html` を開けば動くことを基本とする。価値の中心は「摩擦ゼロの即応性」と「勝敗の明快さ」。
